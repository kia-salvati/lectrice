# B3: library storage and document use cases (done 2026-10-23)

## What was built
- **infra `FsDocumentRepository`** (`DocumentReader` + `DocumentWriter`), under `<storage.data_dir>/library/<sha>/`:
  `original.pdf`, `document.json`, `meta.json`. Every file is written as a temp file in the same
  directory, fsynced, then renamed (`storage/atomic_file.rs`, reusable by B5's audio cache).
  `save` writes the PDF (only if it is not there yet), then `document.json`, then `meta.json` last,
  so `meta.json` marks a complete document. `list_recent`: newest `lastOpenedAt` first (ties by id),
  inline defaults `limit = 20`, `offset = 0`, returns `total`. `save_position` / `mark_opened` change
  `meta.json` under a mutex (they can race). Missing files give `None`; I/O and JSON failures give
  `StorageFailed` with the action + path as detail. It doesn't log.
- **app `documents/`**:
  - `DocumentPipeline` (source → cleaner → build), `is_outdated`, and `reclean` (re-process, save, keep
    `addedAt`, keep `lastSentenceId` only if it still exists).
  - `build.rs`: `CleanedDocument` + `SentenceSplitter` → `Document`. Block and sentence ids run from 0
    without gaps (a block's sentences, then its cue). Blank blocks are dropped. A sentence's `pageIndex` is
    the page of the span it starts in. `speechText` = the sentence without its `spoken: false` spans,
    whitespace collapsed, only when it differs. `spoken`/`text`/`cue` come from `BlockKind`. The title
    falls back to the file name without `.pdf`.
  - `ImportPdf::new(pipeline, reader, writer, clock, max_upload_bytes)`: normalizes the file name (base
    name, trimmed, `document.pdf` if blank) → empty → `UploadMissingFile`, too big → `UploadTooLarge`,
    no `%PDF-` in the first 1 KiB → `PdfInvalid` → SHA-256 id → hit: re-clean if outdated, else
    `mark_opened`; `alreadyInLibrary: true` → miss: process + save.
  - `GetDocument` → `OpenedDocument { document, last_sentence_id }`; marks opened; an outdated document
    is re-cleaned from `find_original_pdf`. Unknown → `DocumentNotFound`.
  - `ListRecentDocuments` (args = `ListOptions`), `SaveReadingPosition` (`SentenceNotFound` if
    `sentenceId >= sentenceCount`).
  - Logs: entry (ids, file name, size), each repository/pipeline result as ids/counts/durations, every
    write. No book text.
- **Tests:** 9 repository tests in a temp dir (`tests/storage_document_repository.rs`: round-trip, layout
  has only the 3 files, a failed write leaves no temp/partial file and no `meta.json`, position/opened
  saved, pagination + ordering, ignores non-id folders, document without `meta.json` is not listed) and
  20 app tests with in-memory fakes (`documents/fakes.rs`): import twice → `alreadyInLibrary` and the
  cleaner ran once, renamed file → same id, version bump → re-cleaned (import and get), not a PDF →
  `PdfInvalid`, unknown id → `DocumentNotFound`, bad sentence → `SentenceNotFound`, sha256 known value,
  builder numbering/pages/speech text.

## Deviations and notes for later steps
1. **`meta.json` holds more than spec §6:** besides `{ addedAt, lastOpenedAt, lastSentenceId }` it copies
   `title, sourceFileName, pageCount, sentenceCount`, so listing recent documents and saving a position
   never parse a whole `document.json` (several MB for a book). It stays infra-private.
2. **`sentenceCount` counts every sentence id, cues included** (ids are 0..n without gaps). B4/F: progress
   = `lastSentenceId / sentenceCount`. `SaveReadingPosition` relies on the same rule.
3. On an import hit with an outdated document, the **uploaded bytes** are re-cleaned (they equal
   `original.pdf`, same sha256); `GetDocument` reads `original.pdf`. A failed re-clean fails the request
   (no fallback to the stale document).
4. Empty uploads raise `UploadMissingFile` (not `PdfInvalid`). B4 converts `upload.max_mb` to bytes for
   `ImportPdf::new` and parses ids with `DocumentId::parse` (bad id → `DocumentNotFound`).
5. **For B4/B5:** a sentence made only of unspoken spans (e.g. just a URL) gets `speechText: ""`.
   `SpeakSentence` and the read-ahead should skip or silence those instead of calling the engine.
6. The sentence-count rule is written twice (infra `StoredMeta` and app `pipeline`), because the domain
   files are frozen. A `Document::sentence_count()` in domain would remove that.
7. `cargo fmt --check` currently reports diffs only in B2's in-progress `lectrice-infra/src/pdf/pdfium_text_source.rs`; B3 files are formatted.
