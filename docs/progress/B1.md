# B1: voice, Kokoro adapter (done 2026-10-23)

## What was built
- **`KokoroSpeechEngine`** (`lectrice-infra/src/speech/kokoro.rs`), implements `SpeechEngine`.
  - `KokoroSpeechEngine::load(&KokoroSettings { model_dir, num_threads })` checks the model dir,
    `model.onnx`, `voices.bin`, `tokens.txt`, `lexicon-us-en.txt`, `espeak-ng-data/{phontab,
    phonindex,phondata,intonations}`, UTF-8 paths and `num_threads ≥ 1` **before** calling
    `OfflineTts::create`. Any problem returns `SpeechEngineUnavailable` (with the missing path in
    the detail) instead of letting sherpa-onnx call `exit()`. The "failed" state is that `Err`:
    the composition root (B4) stores `None` in `AppState.speech_engine`, which health reports.
  - After creating the engine it also checks the model has at least 28 speakers and a valid sample rate.
  - `id()` = `"kokoro-v1.0"` (for the audio cache key). `voices()` = 28 English voices.
  - `synthesize`: unknown/non-English voice → `VoiceUnknown` (before sherpa-onnx, which would fall back
    to voice 0); strips `\0` (sherpa-onnx panics on it); blank text → empty `Audio` at 24 kHz without
    calling the model; no audio from sherpa → `SpeechSynthesisFailed`. Output: 24 000 Hz mono f32, 1x.
- **Voice table** (`speech/voices.rs`): ids 0–27 in speaker-id order (index = `sid`), each with a
  short name ("Heart"), `en-US`/`en-GB` and gender. British voices use the US lexicon (spec §10).
- **`WavEncoder`** (`speech/wav.rs`), implements `AudioEncoder`: hound, 16-bit PCM mono, in memory,
  samples clipped to -1..1, `audio/wav`.
- **Dev command** (`lectrice-api/src/dev_speak.rs`):
  ```bash
  cd backend && cargo run --release -p lectrice-api -- speak --text "…" [--voice af_heart] --out x.wav
  LECTRICE_SPEECH_NUM_THREADS=8 …   # thread count comes from config (default 4)
  ```
  Logs (JSON): engine loaded (engine id, voice count, threads, load seconds), speech synthesized
  (voice id, sample rate, audio seconds, synth seconds, real-time factor), WAV written (path, bytes).
  Never the text.

## Speed (release build, 8 threads, 16-core laptop CPU)
A 48.4-second paragraph (6 Kubernetes-style sentences in one call), 3 runs:
4.23×, 4.67×, 4.63× real time (10.4–11.4 s). Model load ≈ 1.15 s.
**Python measured 4.4×, so Rust is the same speed** (the work is in onnxruntime either way).
The machine was busy during the runs (other agents compiling, load average ≈ 8), so these are
slightly pessimistic. The 12-second sample ran at 3.9× (short inputs have more fixed overhead).

## Tests
- `lectrice-infra/src/speech/voices.rs` (unit): 28 voices with unique ids and names; language and
  gender match the prefix; `af_heart`→3 "Heart" en-US female, `af_alloy`→0, `bf_alice`→20,
  `bm_lewis`→27; non-English and unknown ids have no speaker id.
- `lectrice-infra/tests/speech_kokoro.rs`: missing model dir → `SpeechEngineUnavailable`; a bundle
  without the lexicon (the exact `SHERPA_ONNX_EXIT` case) → `SpeechEngineUnavailable` and the test
  process keeps running; 0 threads rejected. `#[ignore]` (real model): unknown and non-English
  voices → `VoiceUnknown`; real generation is 24 kHz, > 0.5 s, not silent, survives `\0`; blank text
  → empty audio.
- `lectrice-infra/tests/speech_wav.rs`: RIFF/WAVE header, mono 16-bit int at 24 kHz, sample values,
  clipping, mime type.
- `lectrice-api/src/dev_speak.rs` (unit): argument parsing.

## Deviations and notes
1. The dev command is a subcommand, `lectrice-api speak --text … --out …`, not `--speak "text"`.
2. infra has no `tracing` dependency, so the adapter itself doesn't log; the dev command logs the
   numbers, and the B5 speech service should log `{ voiceId, audioSeconds, synthMs }` per call.
3. The engine factory (config `speech.engine` → adapter) is a small `match` inside `dev_speak.rs`; B4
   should move it into the composition root and reuse it there.
4. Not guarded: a model file that exists but is corrupt may still make onnxruntime/sherpa-onnx abort.
   Path checks cover the documented exit cases only.
5. British voices with the US lexicon: listen to `bf_emma` / `bm_george` before deciding if they stay.
