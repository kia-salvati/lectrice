# B2: PDF → cleaned document (done 2026-10-23)

## What was built
- **Survey UNVERIFIED items 9 and 10, settled** (`lectrice-infra/tests/pdf_source.rs`, K8s p9 and CA p25):
  `scaled_font_size()` **is** the effective size (CA body: nominal 20 → scaled 15; K8s 9.96 both), so runs carry
  it. The line-end hyphen arrives as a char with `unicode_value() == 0x02` and `is_hyphen() == Ok(true)`; the
  next char simply sits on the next line (no line-break char). Also found: chars outside the BMP (LinkedIn's
  `𝐦𝐞𝐫𝐠𝐞`, emoji) come as **two UTF-16 surrogate chars**; the run builder recombines them.
- **domain `pdf.rs`** (B2's to extend): `TextRun` gained `baseline` and `line_end_hyphen`; all PDF types derive serde (fixtures).
- **infra `pdf/`**: `PdfiumTextSource::new(libpdfium path)` → `read_runs`: per-char data → `TextRun`s
  (`run_builder.rs`, pure and unit-tested: same font/size/baseline, breaks on visible gaps and on cell-wide gaps
  after a space, `0x02` → `-` + flag, surrogates joined, subset prefixes `DZPUDC+` stripped), page sizes, embedded
  labels, the outline (recursive, with levels, capped against cyclic trees), the `Title` metadata.
  Errors: password/security → `PdfEncrypted`, other load failures → `PdfInvalid`, no runs at all → `PdfNoText`.
- **domain `cleaning/`** (pure): `RuleBasedCleaner` (`CLEANER_VERSION = 1`) and `clean_content`. One module per rule:
  `lines` (3), `bands` (4, 5), `page_labels` (2), `junk` (10), `page_roles` (6, 7), `profile` (1), `footnotes` (8a),
  `line_kinds` (9, 11, 12, 14, 15 per line), `tables` (13), `assemble` (16 + block side of 8b/9/11–15), `code`
  (indent rebuild), `headings` (11, outline match + levels), `hyphenation` (17), `normalize` (18),
  `speech_filters` (19, 20), `block_text` (spans), `fonts`, `page`. Output: `CleanedDocument` blocks with
  `page_index`, spans with `page_index` and `spoken`, and the page labels.
- **infra `text/`**: `SentencexSplitter` (sentencex 0.1.32 boundaries, trimmed byte ranges) + joins after
  e.g., i.e., Dr., Fig., Figs., et al., Eq., Eqs., U.S., U.K., vs., cf., approx., ch. and across split decimals.
- **Dev command** `lectrice-api clean <pdf> --out <dir> [--pages 27-40]` (`lectrice-api/src/dev_clean/`): writes
  `<name>.document.json` (the real saved format, built with B3's `DocumentPipeline`) and `<name>.txt`
  (headings as `##`, `[p. 37 · pdf 61]` markers, unspoken text in `⟦…⟧`, `[CODE — spoken: Code example.]`,
  `[TABLE — spoken: Table.]`, `[CAPTION — not spoken]`, `[FOOTNOTE — not spoken]`, `[SHOWN, NOT SPOKEN]`).
- **Samples for the user's review**: `docs/progress/B2-samples/` — K8s ch14 (code, tables, notes), DDS ch2
  (code, captions), GoF Abstract Factory (code, lists, page refs), CA ch5 (code, footnotes), LinkedIn p8–30.

## User decisions applied
Code: shown, cue "Code example." · Tables: shown, cue "Table." · Captions: shown, silent, no cue ·
Bibliography and copyright pages: shown, all spans silent · TOC and index: dropped · GoF missing spaces left ·
page numbers/labels: metadata only (headers/footers removed, labels in `pages`).

## Known problems seen in the dumps
1. **GoF Table 1.1** (p21–22) is a grid PDFium emits column by column: it comes out as short paragraphs and two
   false `Purpose`/`Scope` headings. Real table structure is phase 2.
2. **Text inside figures** (K8s diagrams) becomes short paragraphs/notes, e.g. `Pods Services hello-pod`.
3. **Bare host names in prose are silent** (`point your browser to shield.mcu.com` → "…to ."), per rule 19.
4. Cross-page paragraph joins are heuristic: a paragraph ending a page with a full line and no punctuation joins the
   next page; one ending with a short line or a sentence end does not (a few mid-sentence splits remain).
5. Front matter: cover/title pages yield small headings; K8s's dedication (p4) splits oddly; "Tweet This Book"
   is spoken (only copyright pages are silent). Copyright pages with two columns show lines in odd order.
6. GoF bibliography entries are split into a bold-key heading + separate lines (silent page, view only).
7. LinkedIn bold labels sometimes join their description (`1. <label> <first words of the text>…`).
8. `10²²` is shown but not spoken (the only exponent found); unmatched footnote markers are silent too.
9. `U.S.` always joins the next sentence (`…in the U.S. The next…` stays one sentence).

## Deviations
1. The cleaner returns the frozen `CleanedDocument` (blocks + spans). Global sentence ids, cue sentences and
   `speechText` are made by B3's `build_document` with `SentencexSplitter`, as the frozen ports define.
2. Footnotes are `note` blocks whose spans are all `spoken: false`, placed after the block open when their page ended.
   B4/B5: such sentences get `speechText: ""` and must be skipped (B3 deviation 5).
3. All digit superscripts are silent and shown as `¹²³` (the survey kept non-footnote ones spoken).
4. `RuleBasedCleaner::clean` raises `PdfNoText` when no block survives cleaning.
5. Image-only pages produce no block (BlockKind has no placeholder); the page still counts in `pageCount`.
6. Infra adapters don't log (repository rule); the dev command logs counts and durations only.
