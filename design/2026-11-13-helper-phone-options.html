Computer helper on the phone: three options

When the phone and a paired computer are on the same Wi-Fi, Lectrice on the computer makes the speech and the phone only plays it. The three options below show the same screens (H1–H9) with the same words. They differ in where the helper lives in Settings, how pairing is laid out and where the player sheet shows the status.

Quiet v2 look, 412 × 915 frames. Use the Theme buttons for light, dark and black. Example names: computer “Kia's laptop”, phone “Galaxy S10+”, book “The Long Book” (invented text). Frames marked 200 % show the largest font size. Spec: docs/android-logic/24-desktop-helper.md.

Option A · “Own page + pages” Recommended by Opus

Settings gets one “Computer helper” row that opens its own page. Pairing is a run of full-screen pages. The player sheet gets a “Computer helper” row under Voice.

Option B · “All in Settings + one pairing sheet”

No extra page: the switch, the computers and “Pair with a computer” sit directly in Settings. Pairing is one tall sheet with the steps Find · Code · Done. In the player sheet the status is the subtitle of the “Audio” row.

Option C · “Own page, inline pairing”

Settings and the Computer helper page are the same as option A (frames A-T1, A-H1, A-H9). Pairing is one page: a found computer opens in place to show the code boxes. The player sheet has no row, only one status line under Speed.
